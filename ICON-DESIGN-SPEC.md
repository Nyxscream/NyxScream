# NYXSCREAM - ICON & LOGO DESIGN SPECIFICATION

## App Icon Design

### Color Scheme:
- Primary: #0D0221 (Void Black)
- Accent: #00F0FF (Electric Blue)
- Secondary: #FF003C (Scream Red)
- Background: #1A0A2E (Shadow)

### Design Concept:
- Center: Streaming play symbol (triangle)
- Background: Dark void with electric blue glow
- Overlay: "NYX" text or microphone icon
- Style: Modern, minimal, professional
- Vibe: Dark, mysterious, professional

### Technical:
- Format: PNG with transparency
- Master Size: 1024x1024px
- Safe Area: 900x900px
- Corner Radius: Let OS handle

## Recommended Icon Style:

Option 1: "NYX" Text Icon
- Large bold "NYX" 
- Electric blue on void black
- Glowing effect around text
- Modern sans-serif font

Option 2: Streaming Symbol
- Play triangle (▶)
- Microphone outline
- Sound wave pattern
- Electric blue glow

Option 3: Scream Theme
- Mouth/scream symbol
- Sound waves
- Dark void background
- Electric accents

## Logo Design

- Large horizontal version for splash
- Include full "NYXSCREAM" text
- Tagline: "Where Darkness Meets Sound"
- Color: Electric blue on void black

## Splash Screen

- Background: Gradient (Void to Shadow)
- Logo: Large centered
- Tagline: Bottom
- Animation: Fade in electric glow
